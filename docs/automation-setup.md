# 対象アプリのオートメーション設定ガイド

## 実装

- 値札設定と実計測画面の両方から `AutomationSetupView` を開く。
- 8手順で対象名、開いたときの登録、閉じたときの登録、実動作確認を案内。
- 対象名と現在の手順をUserDefaultsに保存する。これは案内の進み具合であり、OS側の登録状態ではない。
- 開閉のアクション名と対象名をタップでコピーできる。
- `shortcuts://` でショートカットを開く。戻っただけでは次へ進めない。
- 初回開始・最後の試用時に、計測が停止していればShortcuts方式へ切り替える。別方式の計測中は切り替え不可。
- 最後は値札設定で選んだ方式・デザインの計測画面へ進み、待機開始・値札開始・対象アプリの開閉・停止保存を試す。
- ガイドのやり直しはOS側のオートメーションを削除しない。複数SNSは各アプリの開閉をそれぞれ登録する。

## 公式仕様で確認した事実

- [Apple: URLスキーム](https://support.apple.com/ja-jp/guide/shortcuts/apda283236d7/ios)：`shortcuts://` は最後に使用した状態でアプリを開く。特定のオートメーション登録画面への遷移を保証しない。
- [Apple: パーソナルオートメーション作成](https://support.apple.com/ja-jp/guide/shortcuts/apdfbdbd7123/ios)：作動条件・アクションをユーザーが選び、保存する。

## 判断・未検証

公開されたURLスキームを使用し、個人用オートメーションの自動登録・読み取りを前提としない。画面名のOS差は案内に明記。登録成功を自己申告によるガイド進行と混同しない。

UIテストは手順の再開、最後の未確認表示、計測画面への遷移を確認する。ショートカット側の保存、バックグラウンドでの開閉通知、実機で金額が増減停止することは実機確認が必要。技術的な連携とApp Store審査承認は別。
