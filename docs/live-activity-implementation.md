# Live Activity implementation

The app requests `Activity<MoneyActivityAttributes>` synchronously from a foreground action. `MoneyLiveActivityController` provides `start(record:style:isCounting:) throws`, `update(record:isCounting:) async`, `end(record:) async`, and `endOrphans() async`. `status` is a readable Japanese diagnostic message. A rejected request throws and records the reason; no placeholder success is reported. Existing activities block a second request until ended. On relaunch, orphan cleanup ends old activities while preserving a newly requested activity owned by this controller.

The shared ActivityKit model compiles into both targets and does not depend on SessionRecord. Each sample contains numeric yen, hourly rate, elapsed milliseconds, counting status, and a real sample timestamp. Lock screen and expanded island show yen with two decimals and hourly rate; compact and minimal island use whole yen below 10,000 and whole ten-thousand yen (`万`) above, matching the app preview. Compact amounts are approximations; expanded shows the detailed snapshot. All presentations retain money, including minimal. Paper/ink styles use the app palette; the island uses paper-colored ink on the system black surface.

Each counting sample has a 15-second stale date. The stale UI says previous amount and retains the last sample time. Counting means the app reports an accruing interval, not proof of continued background execution. The extension never calculates an extrapolated money amount or uses a timer as a substitute. ActivityKit does not promise one update per second or unrestricted background app execution. Device QA must verify lock screen, compact/minimal/expanded island, disabled permission, dismissal, relaunch orphan cleanup, and large amounts. No device runtime or update-frequency claim has been verified on Windows.

`project.yml` embeds the `MoneyLiveActivityWidget` app extension with bundle identifier `com.moshidopa.app.liveactivity`, a separate WidgetKit Info.plist, shared attributes in both source lists, and `NSSupportsLiveActivities` in the app plist generated by XcodeGen. Regenerate the project with XcodeGen before building.

Official references: [ActivityConfiguration](https://developer.apple.com/documentation/widgetkit/activityconfiguration), [Displaying live data with Live Activities](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities), [Meet ActivityKit](https://developer.apple.com/videos/play/wwdc2023/10184/).
