```text
MoshiDopa_iOSの docs/ios-redesign-plan.md と参照先の3調査書に従い、
P1（最小ネイティブビルド・CI・画面撮影）とP2（PiP金額カウンターPoC）を実装してください。

PiPの背景更新・SNS音声共存・Shortcuts・署名は実機検証と分けてください。
実機を使えない場合は試験用ビルドと再現手順まで完成させ、P2は未検証と報告してください。
実施していない試験を成功扱いせず、P2成立前に全面UI実装へ進まないでください。

完了条件はP1の実CI成功、P2実装の親レビュー完了、実機試験可能な成果物と手順の整備、
実施できた試験結果と未実施項目の明確な報告です。
App Store提出とmainへのマージはこのGoalに含めません。
```

このGoalの成果物引き渡しと、製品のP2合格は別。未実機検証で前者を終えても、後者の合格は記録しない。P2合格後にP3〜P5の実装Goalを設定する。
